# The First Unit — Speakout A2

## Upload to GitHub
1. Unzip this package.
2. In your GitHub repository, choose Add file → Upload files.
3. Select ALL the extracted files together. There are no folders to upload.
4. Commit changes.
5. Open Settings → Pages → Deploy from a branch → main → / (root) → Save.
6. After publication, use Visit site and share the link.

index.html, style.css, app.js, data.js, all seven MP3 files, and both family-tree PNG images must be next to each other in the repository root.

Both workbook lessons are on one page. The student completes the exercises herself. The website checks written answers and provides Russian hints, without showing an answer key. Speaking activities are self-reviewed.

The downloadable report preserves first submitted answers. Later corrections do not replace them. Responses stay in the student's browser until she downloads and sends the report. Automatic collection is not connected.
